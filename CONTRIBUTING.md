# Contributing to LevCodeLab

This repository powers the `LevCodeLab` GitHub profile README and its weekly pulse GitHub Action.

## Local Verification

```bash
node --test test/pulse.test.mjs
node scripts/update-pulse.mjs
```

## Style Rules

1. Keep every sentence short and easy to read.
2. Keep all SVG graphics and badges pure dark monochrome (`#141418`, `#26262E`, `#FFFFFF`).
3. Do not add external social links or corporate buzzwords.
